PicPoints is the most advanced, developer-friendly **interactive image map** and **floor plan builder** for WordPress. Built for extreme performance and modern web standards, this **hotspot plugin** handles hundreds of interactive elements effortlessly without lagging your website.

Unlike traditional **image mapping tools** that break during WordPress theme updates, PicPoints renders entirely inside an isolated **Shadow DOM**. This guarantees 100% CSS and JS isolation, your theme's styles will never break your **interactive maps**, and your maps will never slow down your site page speed.

== Installation ==

1. Upload the `picpoints` folder to the `/wp-content/plugins/` directory, or install the plugin directly through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Look for the "PicPoints" menu item in your WordPress dashboard left sidebar to start building.
4. Copy the generated shortcode `[picpoints id="..."]` and paste it into any page, post, or widget area.


== Frequently Asked Questions ==

= I installed the plugin, what's next? =
Once you've installed the plugin, you can start creating your first interactive map right away. Just open the PicPoints menu in your WordPress dashboard, create a new scene, setup canvas background and begin adding interactive markers and shapes. Your map will be ready to embed on any page in minutes.

= Does PicPoints work with page builders? =
Without a doubt, PicPoints works with most popular web page builders such as Elementor, Divi, Beaver Builder, Visual Composer, WP Bakery, Brizy, Blocks, and many others.

= Where is the developer version hosted? =
The developer version is available [here](https://github.com/yalogica/picpoints).

= Will this plugin slow down my page load speed? =
No. PicPoints is built with performance in mind. Thanks to lightweight vector rendering and modular architecture, it can handle over a thousand active elements without visible performance drops or layout shifting.

= Will my theme's CSS break the maps layout? =
Never. PicPoints utilizes **Shadow DOM encapsulating technology**. It encapsulates all styles inside a shadow tree, meaning your active theme cannot inject or override the CSS of your interactive maps.

= Can I link markers to WooCommerce products? =
Yes! You can use rich-text popups to insert product links, images, and prices. With the Pro version, you can use the custom JS/API section to create deep integration like "Add to Cart" directly from the image hotspot.
